# Соглашения для исполнителя: package-sdk

Этот файл читают кодовые агенты и люди, которые меняют репозиторий. `CLAUDE.md`
ссылается сюда же; машиночитаемая часть (соседи, установка, проверки) —
[`.agents/runner.yaml`](.agents/runner.yaml). Что делает SDK — в
[README.ru.md](README.ru.md).

## Раскладка

- `src/package_sdk/` — библиотека и CLI `package-sdk`: модель и источники пакетов,
  `check`, песочница (`sandbox.py`), каталог обычными ресурсами ядра (`apply.py`),
  источники, lock и единый план установки (`install/`), правка с
  сохранением стиля (`edit.py`), экспорт, заготовки (`scaffold.py`), образы
  (`image.py`), среда наблюдателя (`connector/`), MCP-сервер автора (`mcp.py`,
  `package-sdk mcp`).
- `plugin/package-author/` — плагин Claude Code автора пакетов: скиллы, хук согласия
  `confirm_apply.py` на `pkg_apply`, сервер MCP плагина (`.mcp.json`); marketplace —
  `.claude-plugin/marketplace.json` в корне. Скиллы — на русском, как документация.
- `schema/v1/` — JSON Schema формата пакетов, планов и блокировок; в колесо
  попадает как `package_sdk/schemas`.
- `tests/` — тесты; `tests/umbrella/` — тесты перенесённых инструментов на
  обезличенном снимке пакетов `tests/fixtures/umbrella` (`PACKAGE_SDK_UMBRELLA`
  переключает их на живое дерево пакетов); `tests/contract/` — сверка со
  снимками контрактов ядра.
- `ci/quickstart.py` — job «quickstart» (`.github/workflows/quickstart.yml`, SC-001):
  исполняет страницу «Пакет за 10 минут» руководства суперпроекта в чистом каталоге
  и укладывается в 10 минут. Ревизия страницы закреплена в `ci/quickstart-pin.json`
  (коммит и отпечаток её команд); разметка страницы и проверка закрепления — в
  docstring модуля.
- Соседи по плоской раскладке — path-зависимости экстр из `pyproject.toml`:
  `../control-plane` (`sandbox`: доменный код ядра; `connector`: клиент ядра),
  `../skill-sdk` (`skills`) и `../platform-auth-sdk` (зависимость ядра). Они
  стоят на ревизиях, закреплённых суперпроектом, и доступны **только для
  чтения**: правка соседа — отдельная задача в его репозитории.

## Сборка и проверки

Проект — [uv](https://docs.astral.sh/uv/), Python 3.12. Всё, что зовёт CI, —
цели `make`:

```bash
make install     # uv sync --frozen --all-extras
make lint        # ruff check + ruff format --check
make typecheck   # mypy (strict; перенесённые модули пока в исключениях)
make test        # pytest со всеми экстрами
make check       # всё перечисленное подряд
```

Без экстр тесты песочницы и контрактов ядра пропускаются — ставь через
`make install`. Тестам не нужны база и сеть. Сборка образов в `tests/test_image.py`
идёт только при `PACKAGE_SDK_DOCKER=1` и Docker рядом; по умолчанию она
пропускается.

## Перед сдачей

- `make check` зелёный. Тесты — последовательно, один прогон за раз.
- Меняешь поведение — тест в том же коммите.
- Меняешь формат пакета — `schema/v1/`, фикстуры `tests/fixtures/` и README в том
  же коммите. Поле `spec` вида — это тело API ядра без слоя перевода: поле,
  которого нет в ядре на закреплённой ревизии, — выдуманный контракт
  (`tests/contract/test_core_openapi.py`).
- Меняешь зависимости или сдвинулся указатель ядра в суперпроекте —
  `uv lock` и `uv.lock` в том же коммите; `THIRD_PARTY.md` и `sbom.json`
  пересобираются по `CONTRIBUTING.md`.
- Меняешь команду или флаг, которые есть в быстром старте руководства, — прогони
  `python3 ci/quickstart.py run --superproject <клон суперпроекта>` (с Docker; без
  него `--db none`). Правка страницы в суперпроекте — `pin update` и прогон в SDK.
- Модуль из исключений mypy (`[[tool.mypy.overrides]]`) доведён до strict —
  убери его из списка.

## Правила

- SDK нейтрален к домену и продукту: в коде, схемах и заготовках нет имён
  бизнес-доменов, вендоров и продукта. Стражи — `tests/test_neutrality.py` и
  `tests/test_white_label.py`; единственные исключения — идентификаторы формата,
  перечисленные в страже. Примеры предметных пакетов — в фикстурах, не в коде.
- Документация — на русском, `README.md` — на английском; имена API и сущностей —
  на английском. Комментарии в коде — как в окружающем коде.
- Не коммить секреты, `.env`, абсолютные локальные пути, внутренние адреса и
  артефакты сборки (`.venv/`, кэши, `dist/`).
- Не трогай `main` и чужие ветки.
- Не делай того, чего нет в задаче: найденное попутно — в отчёт, а не в код.
